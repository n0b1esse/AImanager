# Фаза 0 — что нужно сделать до разработки (1 неделя)

Разделение: 🧑 = делает владелец (внешние действия, код не поможет), 🤖 = делает агент/разработка.

## 1. ИП и налоги 🧑

- [ ] Открыть/подтвердить ИП КГ (если ещё не открыто). Выяснить налоговый режим: общий / упрощённый (для услуг) / патент — что выгоднее при выручке в сомах/USD.
- [ ] Проверить право на **Парк высоких технологий КР** (0% налог на прибыль и НДС по экспорту ПО) — ведём разработку ПО на экспорт, это профильная категория. Консультация с бухгалтером/юристом ПВТ.
- [ ] Расчётный счёт в банке (лучше там же, где эквайринг).
- [ ] Реквизиты для B2B-инвойсов (для крупных клиентов в пилоте).

## 2. Платежи (критический путь) 🧑 🤖

Кандидаты (решение 2026-11-16): на старте **MBank (MBank Business)** или **Финик (finik.kg)** с интернет-эквайрингом для ИП КГ; позже выбрать основной банк по условиям. (**проверить лично, условия не сверены вживую**)

Что спросить (в обоих):
1. Интернет-эквайринг для ИП КГ: единовременная плата, % за транзакцию, месячная абонплата?
2. Карты каких платёжных систем принимаем (Visa/MC/Элкарт); RF-карты (Мир) — проходят ли?
3. Рекуррентные платежи (автосписание подписки) есть? Если нет — токенизация карты и напоминания по email?
4. API: webhook о статусе платежа, подписки, возврата? Документация? У Финика — условия интеграции (API/QR)?
5. Фискализация по законодательству КР: чек формирует банк или нужен отдельный ОФД?
6. Сроки подключения и вывод на расчётный счёт?

Пока банк не выбран — биллинг в разработке делается за абстракцией `PaymentProvider` с ручной активацией как first-class режим (это же fallback навсегда).

## 3. Юридика и контент 🧑 🤖

- [ ] Домен (.kg / .com — решить; для РФ-фазы понадобится .ru-лендинг позже).
- [ ] Публичная оферта: предмет (лицензия/доступ к сервису), ответственность клиента за финальное одобрение ответа, отзыв данных, возвраты. **Составляет юрист, мы готовим черновик-скелет.**
- [ ] Политика конфиденциальности + согласие на обработку ПД: что храним (тексты отзывов = публичные данные + возможные ПД покупателей; WB-токен и AI-ключ — шифруем).
- [ ] «Парольная политика»/2FA для админов — пишется как часть SECURITY.md.
- [ ] Waitlist-лендинг (одна страница: что делает сервис, три тарифа, форма заявки, контакты). 🤖 — делаем в Фазе 0 после домена.
