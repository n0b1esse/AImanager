Почему шаблонные ответы не работают

Менеджеры устают от рутины

На среднем кабинете — десятки отзывов в день. Копипастая Ответы, менеджер отвечает то «Спасибо за отзыв», то забывает ответить вовсе — и карточка проседает в выдаче.

Покупатели распознают банальщину

«Благодарим за обратную связь!» под каждым отзывом снижает доверие. Ответ, в котором видно конкретику отзыва, работает на репутацию и возвраты.

ИИ врёт в нюансах ниши

Без ниши ассистент обещает «вылечить акне» или «выдержит любой вес». Мы ограничиваем что ИИ может обещать — по каждой нише отдельно.

Три шага — и отзывы отвечают сами

1

Подключаете магазин WB

Вставляете токен с категорией «Вопросы и отзывы». Мы проверяем доступ к API и сразу забираем неотвеченные отзывы. Токен хранится зашифрованным — его не увидит даже наша поддержка.

2

Подключаете свой ИИ

OpenAI, любой OpenAI-совместимый endpoint или локальная Ollama. Выбираете нишу кабинета — и ассистент получает «навыки общения» этой ниши: лексику, границы утверждений, тон.

3

Одобряете — или включаете автопилот

Сначала вручную: смотрите, правите, публикуете. Когда доверились — включаете полный автоматический режим для этого магазина. Публикация только после вашего действия.

Ниши — это «навыки общения», а не просто промпт

Каждый пак: фактура ниши, запрещённые утверждения, формула «если факт неизвестен», few-shot примеры и эскалация на ручную проверку.

Частые вопросы

Куда уходит текст отзыва?

В ИИ-провайдера, которого вы подключаете сами (OpenAI / совместимый endpoint / ваша Ollama). То есть текст уезжает в тот ИИ, с которым вы и так работаете. Если подключаете локальную Ollama — никуда не уезжает. Никогда не пишем туда ничего сверх полей отзыва, которые вы видите.

Публикует ли сервис без моего ведома?

Нет. По умолчанию ответ сначала приходит вам: «проверьте и опубликуйте». Полный автопилот включается отдельно, на каждый кабинет, и тоже имеет эскалацию — опасные темы (брак, суд, отравление) всегда идут человеку.

Что с моим WB-токеном?

Хранится зашифрованным (Fernet), в открытом виде никогда не отображается — даже мы его не видим. Используется только для официального API WB: чтение отзывов и публикация ответов после вашего апрува.

Откуда сервис берёт факты о товаре?

Только из данных карточки и отзыва. Если факт неизвестен — ИИ не выдумывает, а отвечает универсальной формулой («уточним у команды и вернёмся») и отдаёт отзыв вам на ручную проверку.

А если WB-API меняется?

Сервис работает только через официальный API Wildberries, проверка контракта — со своей стороны. После неоднозначного сбоя (timeout/5xx) мы перепроверяем состояние отзыва перед любой повторной публикацией — дублей не будет.
