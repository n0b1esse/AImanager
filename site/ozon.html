Ответы на отзывы Ozon — автоматически

Авто-Отвеччик подключается к Ozon Seller API (Client-Id + Api-Key), забирает новые отзывы и отвечает на них вашим ИИ в стилистике вашей ниши — после вашего апрува или автономно. Один сервис — Wildberries и Ozon.

Честно о требованиях Ozon

Ozon открывает API отзывов только продавцам с подпиской «Управление отзывами» или Premium Pro. Без неё методы /v2/review/list и /v1/review/comment/create вернут отказ. Перед запуском проверьте в кабинете Ozon: Продавцу → Подписка → «Управление отзывами».

  • Client-Id и Api-Key — используем только для официального Seller API Ozon
  • Ответ публикуется как комментарий продавца к отзыву (официальный метод)
  • Отзыв помечается Processed — чтобы не отвечать дважды
  • Неоднозначный сбой → перепроверка комментариев, дублей не будет

Как подключить Ozon

  1. 1. В кабинете Ozon: Аккаунт → Seller API → API-ключи — создайте ключ с правом на «Управление отзывами»
  2. 2. В Авто-Отвеччик: Магазины → Добавить → Ozon — вставьте Client-Id и Api-Key (хранятся зашифрованно)
  3. 3. Проверяем подключение, забираем новые отзывы — и вперёд в очередь
