Ozon Seller API для отзывов: что умеет и как подключить

8 минут · Команда AImanager

Что важно знать в начале

Ozon открывает API отзывов только продавцам с подпиской «Управление отзывами» или Premium Pro. Без неё оба нужных метода вернут отказ. Проверяйте в кабинете: Продавцу → Подписка.

Аутентификация

Два заголовка к каждому запросу: Client-Id (идентификатор кабинета) и Api-Key (ключ на странице «Аккаунт → Seller API → API-ключи»). Точно так же, как в остальном Ozon Seller API.

Основные методы

МетодЗачем
POST /v2/review/listСписок отзывов (фильтр status=NEW — неотвеченные; пагинация через last_id, limit 20–100)
POST /v1/review/comment/listКомментарии к отзыву — наш способ проверить «уже отвечал я или нет»
POST /v1/review/comment/createОтвет продавца; mark_review_as_processed: true помечает отзыв обработанным

Типичные поля отзыва

id, sku, text, rating (1–5), status, published_at, comments_amount. То, что нам нужно для генерации ответа: текст, оценка, артикул.

Чего избегать при интеграции

  • Наивный retry при сетевом сбое: отправили ответ, потеряли подтверждение — и отправили второй. Всегда сначала comment/list и проверка наличия вашего комментария.
  • Отвечать на отзывы со статусом не-NEW или с comments_amount > 0 от владельца.
  • Хранить ключ в открытом виде: шифруйте тем же способом, что и токены WB.

Что делает AImanager

Ровно этими методами мы забираем новые отзывы, пишем ответы вашим ИИ и публикуем их после вашего апрува. Детали — на странице для Ozon. Wildberries и Ozon — в одном кабинете.
